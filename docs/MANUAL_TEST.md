- [ ] `npx tsc --noEmit` → 타입 오류 0개 확인

> 홈 스트릭 카드 탭으로 진입

- [ ] 최근 30일 막대 그래프 표시
  - [ ] 제출(초록) / 지각(노랑) / 미제출(빨강) / 숙제없음(회색) 색상
- [ ] 30일 통계 카드 (마감 전 제출 / 지각 / 미제출 일수 + 제출률)
- [ ] 스트릭 규칙 안내 카드
- [ ] 뒤로가기 버튼 동작

## PART 5 — 학부모 기능

> 학부모 계정으로 로그인 후 진행 (자녀 계정과 연동 필수)

### 5-1. 홈 탭

- [ ] 흰 헤더 + 자녀 탭 칩 표시 (활성: 주황색)
- [ ] 주황 그라데이션 출결 카드 (오늘 자녀 출결 상태)
- [ ] 오늘 숙제 — 미제출(빨간 카드) / 완료(초록 카드)
- [ ] 결석 시 사유 선택 칩 표시 (병원 / 가족행사 / 기타)
  - [ ] 칩 선택 → "선생님께 전송하기" 버튼 표시
  - [ ] 전송 탭 → 선생님 명렬표에 즉시 반영 확인

### 5-2. 자녀 전환

> 자녀 2명 이상 연동된 계정으로 테스트

- [ ] 자녀 탭 칩 탭 → 전환 화면 이동
- [ ] 자녀 목록 표시
- [ ] 다른 자녀 선택 → 홈 데이터 즉시 변경 확인

### 5-3. 자녀 추가 연동

- [ ] 자녀 연동코드 입력
- [ ] 유효한 코드 → 자녀 계정 연결 확인
- [ ] 연결 후 자녀 탭 칩에 즉시 반영

### 5-4. 숙제 탭

- [ ] 선택된 자녀의 숙제 목록 표시
- [ ] 숙제 카드 탭 → 자녀 숙제 상세 화면 이동
  - [ ] 제출물 이미지 표시
  - [ ] 선생님 피드백 표시
  - [ ] 뒤로가기 → 홈이 아닌 숙제 목록으로 이동 확인

### 5-5. 출결 탭

- [ ] 선택된 자녀의 출결 현황 표시
- [ ] 결석 사유 칩 선택 → 전송 (5-1 항목 참조)

### 5-6. 공지 탭

- [ ] 공지 목록 표시
- [ ] 공지 탭 → 읽음 처리 후 Firestore `read_by` 배열에 uid 추가 확인
- [ ] 중요 공지 강조 표시

### 5-7. 내정보 탭

- [ ] 이름 / 역할 표시
- [ ] 알림 설정 — 숙제 알림 / 출결 알림 / 공지 알림 각 토글
  - [ ] 토글 변경 후 Firestore `notif_prefs` 저장 확인
- [ ] 로그아웃

## PART 6 — 크로스 역할 연동 테스트

> 두 역할을 동시에 사용하여 데이터 연동을 검증

### 6-1. 숙제 전체 사이클

- [ ] **선생님** 숙제 출제 → **학생** 홈에 즉시 D-Day 카드 표시
- [ ] **학생** 숙제 제출 → **선생님** 검사 목록에 즉시 반영
- [ ] **선생님** 피드백 등록 → **학생** 홈 카드에 피드백 텍스트 반영
- [ ] **학부모** 자녀 숙제 상세에서 제출물 + 피드백 확인 가능

### 6-2. 출결 연동

- [ ] **선생님** 결석 입력 → **학부모** 홈 출결 카드에 즉시 반영
- [ ] **학부모** 결석 사유 전송 → **선생님** 명렬표에 사유 즉시 표시

### 6-3. 공지 연동

- [ ] **선생님** 공지 작성 → **학생** / **학부모** 공지 탭에 즉시 표시
- [ ] **학생** 공지 읽음 처리 → **선생님** 읽음 현황 수 증가 확인
- [ ] 중요 공지 → **학생** 홈 하단에 중요 공지 카드 표시 확인

### 6-4. 실시간 동기화

- [ ] 선생님 A기기에서 출결 입력 → 선생님 B기기에서 즉시 반영

## PART 7 — FCM 푸시 알림

> 실기기 필수. 알림 권한 허용 상태에서 테스트.

### 7-1. 권한 및 토큰

- [ ] 앱 최초 실행 → 알림 권한 요청 팝업 표시
- [ ] 허용 후 Firestore `users/{uid}.fcm_token` 저장 확인
- [ ] 알림 거부 시 `fcm_token: null` 저장 확인
- [ ] 앱 재실행 후 토큰 갱신 확인

### 7-2. 숙제 피드백 알림

- [ ] 선생님 피드백 등록 → 학생 기기 푸시 알림 수신
- [ ] 학부모 기기에도 동일 알림 수신
- [ ] 알림 탭 → 해당 숙제 화면으로 딥링크 이동

### 7-3. 미제출 수동 알림

- [ ] 선생님 숙제 검사 화면 → 미제출 학생 알림 버튼 탭
- [ ] 해당 학생 기기 푸시 알림 수신
- [ ] 해당 학생 학부모 기기 푸시 알림 수신

### 7-4. 출결 알림

- [ ] 선생님 결석 입력 → 해당 학부모 기기 즉시 알림 수신
- [ ] 지각 입력 → 학부모 알림 수신

### 7-5. 공지 알림

- [ ] 공지 작성 저장 → 대상 역할 기기 알림 수신

### 7-6. 앱 내 알림함

- [ ] FCM 수신 내역 알림함에 동시 저장 확인
- [ ] 알림 권한 거부 상태에서도 알림함 내역 조회 가능 확인
- [ ] 읽음 처리 후 미읽음 배지 감소 확인

## PART 8 — 엣지 케이스 & 예외 처리
